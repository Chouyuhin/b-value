# External data for the b-value claims test (downloaded 2026-10-23)

- gcmt/            Global CMT catalogue, ndk format. jan76_dec20.ndk + monthly files 2021-2023.
                   Source: https://www.globalcmt.org (ldeo.columbia.edu/~gcmt/projects/CMT/catalog/)
- gnss/WangShen2020_TableS4_velocities.txt
                   Wang & Shen (2020, JGR Solid Earth) site velocities, ITRF2008 and Eurasia-fixed, 2,403 sites.
                   Harvard Dataverse doi:10.7910/DVN/C1WE3N, Table S4.
- gnss/ds01_gnss_velocity_field.txt
                   Sichuan-Yunnan field, South China Block-fixed, 419 sites (copied from ProjectB reference).
- hotsprings/chen2014_wsichuan_springs.csv
                   32 springs/wells with coordinates, western Sichuan (LMSF, MJF, XSHF, ANHF zones).
                   Chen et al. 2014, PMC4032713, Table 1.
- hotsprings/acsomega2021_sichuanyunnan_he_sites.csv
                   5 hot-spring gas sites, Sichuan-Yunnan block. ACS Omega 2021, doi:10.1021/acsomega.1c04533.
- hotsprings/LiEtAl_XJ_RRF_springs_nocoords.xlsx
                   Xiaojiang-Red River intersection springs, hydrochemistry only, NO coordinates.
                   Mendeley Data doi:10.17632/kxt9df6ngg.1
Heat flow: ~/🎓Academic/Research/🪺Dataset/热流数据/ (heatflow5_china.xlsx, global_heat_flow.txt), not copied.
- hotsprings/water-2850194-supplementary.xlsx  -> yao2024_xsh_xj_springs.csv
                   Yao et al. 2024, Water 16(5):680, Table S1: 74 springs along Xianshuihe-Xiaojiang fault zone,
                   with coordinates (note: Longitude/Latitude headers are swapped in the original; corrected in the CSV).
